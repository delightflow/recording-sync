1. 처리하는 정보와 목적

선택한 파일
사용자가 Android 시스템 선택기로 승인한 폴더와 하위 파일의 본문, 이름·경로·크기·수정 시각·내용 해시를 단방향 백업, 중복 재전송 방지와 수정본 보관에 사용합니다. 파일에는 녹음·영상·문서 및 민감한 내용이 포함될 수 있습니다.
연결 계정
계정의 이메일·표시 이름, Google 계정의 permission ID와 OAuth 인증 정보를 계정 표시·접근 승인·클라우드 전송에 사용합니다. Google 비밀번호를 앱에 직접 입력받아 저장하는 방식은 사용하지 않습니다.
작업 설정·이력
선택한 폴더, 백업 목적지·감지 주기·네트워크/충전 조건, 전송 세션, 원격 파일 ID·내용 해시와 처리 결과를 백업 실행·재개·오류 확인에 사용합니다.

자체 회원가입은 제공하지 않고 기존 클라우드 계정을 연결합니다. 앱이 사용자의 모든 휴대폰 파일을 자동으로 읽는 것은 아니며 필요한 폴더를 직접 선택해야 합니다.

2. 전송되는 곳과 외부 서비스

공개 후보의 파일 백업은 사용자가 연결한 본인 Google Drive에 파일·메타데이터를 보냅니다. Google의 drive.file 범위만 요청하며 전체 Drive나 Gmail 범위를 요청하지 않습니다. 계정과 전송 원장·세션을 계정 식별자에 묶고, 계정 재연결 시 자동 백업을 중지합니다. 확인된 계정에 묶인 폴더만 전송하며 기존 폴더를 새 계정으로 자동 이전하지 않습니다.

모델을 준비할 때 Hugging Face 배포 서버와 통신하며 IP 등 연결 정보가 수반될 수 있습니다. 로컬 음성 추론은 전사 서버로 음성을 보내지 않습니다. 사용자가 결과 공유 버튼을 누르면 선택한 시스템 공유 대상에 본문이 전달됩니다. Google 인증 SDK·Drive·모델 호스팅의 처리는 각 제공자 정책도 적용됩니다. 광고·분석·결제 SDK를 직접 추가하지 않았다는 이유로 모든 외부 SDK 처리가 없음을 보장하지 않습니다.

3. 휴대폰 로컬 전사와 제공 범위

Whisper tiny 모델 약77.7MB를 사용자가 선택해 다운로드하고 SHA256을 확인한 뒤 휴대폰에서 음성을 처리합니다. 모델·원본 URI/이름·내용 해시·작업 상태·전사 결과는 이 Android 사용자의 앱 전용 저장소에 보관합니다. 5분·64MiB 이하 화면 내 처리의 시험 기능이며 속도·정확도·발열·장시간 처리는 실기기 검증 전입니다.

앱 자체 사용자 계정은 없으며 Google 연결은 백업 목적지 승인입니다. 로컬 전사 결과는 이 Android 사용자 기기 안에서 공통으로 보관되고 Google 계정별 로그인 저장소가 아닙니다. 다른 사람과 기기를 공유하는 경우 이 구분을 확인해 주세요. 운영자 공용 전사 서버, 공통 연결 코드, 사용자 키를 받는 BYOK, PC 자동 연결은 이번 공개 후보에서 제공하지 않습니다. 별도 개인 개발 변형의 중계/PC 기능을 공개 서비스로 제공하는 것은 아닙니다.

4. 보관과 삭제

  • Android 기기. 폴더/예약 설정과 전송 원장·로그는 앱 전용 저장소에 보관합니다. DB 처리 이력은 최근 500개를 유지하고 화면에는 최근 100개를 표시합니다. 파일 해시·원격 ID 등 중복 방지 원장은 로그와 별도로 보관합니다.
  • 계정 연결 해제. 기기에 저장한 해당 계정 인증 토큰을 제거합니다. 기존 처리 이력·클라우드 파일·Google 계정 자체까지 삭제하지 않습니다. 서비스의 앱 접근 승인은 각 계정 설정에서 별도로 철회할 수 있습니다.
  • 폴더 연결 해제. 백업 작업 설정을 제거하며 휴대폰 원본과 클라우드 백업은 보존합니다. 앱은 원본 삭제를 클라우드에 전파하지 않습니다.
  • 앱 데이터 삭제·제거. Android 설정에서 앱 데이터를 지우거나 앱을 제거하면 앱 전용 기기 정보가 제거됩니다. 클라우드에 이미 보관한 원본·수정본·전사본은 각 서비스에서 직접 관리합니다.

연결 해제와 파일/데이터 삭제는 다른 동작입니다. 모든 정보를 일정 일수 뒤 자동 삭제한다고 약속하지 않습니다. 사용자가 소유한 클라우드 파일의 보관 기간과 삭제는 사용자의 관리 및 해당 서비스 정책에 따릅니다.

5. 보안 조치

클라우드 요청은 HTTPS를 사용합니다. Android 인증 토큰과 전송 세션 정보는 Android Keystore의 키로 AES-GCM 암호화해 저장합니다. 시스템 백업과 기기 이전에서 앱 내부 데이터를 제외합니다. 오류 이력에는 토큰·업로드 주소가 포함될 수 있는 원시 응답을 그대로 남기지 않도록 처리합니다. 기기와 모든 클라우드 사이의 종단간 암호화나 모든 위험의 제거를 보장하는 기능은 아닙니다.

6. Android 권한

인터넷·연결 상태
계정 승인·클라우드 전송과 사용자가 정한 네트워크 조건 확인에 사용합니다.
알림·dataSync 서비스
사용자가 시작한 백업의 실행·진행 표시·중지에 사용합니다.
재부팅 수신
사용자가 켜 둔 시스템 예약 작업을 복구하는 데 사용합니다.
선택한 폴더
Android 시스템 선택기에서 사용자가 승인한 폴더 접근을 사용합니다. 폴더가 승인되지 않았거나 권한이 회수되면 해당 파일을 읽을 수 없습니다.

마이크·SMS·통화기록·모든 파일 접근·광범위 사진/영상 권한은 선언하지 않습니다. 이미 만들어진 통화 녹음 파일의 백업을 위해 통화기록을 읽지 않습니다.

앱 안에서 계정/폴더 연결을 해제하고 Android 설정 및 해당 Google 계정 설정에서 접근 승인을 관리할 수 있습니다. 로컬 앱 데이터와 사용자가 소유한 클라우드 파일의 삭제 범위는 위 설명을 확인해 주세요.

개인정보 열람·정정·삭제·처리 정지 등 관련 문의는 contact@patentwith.com으로 보내 주세요. 운영자 전승열이 처리 범위와 문의 내용을 확인합니다. 처음부터 비밀번호·인증 코드·녹음 원본을 보내지 마세요. Google 계정 자체나 사용자가 직접 소유·관리하는 클라우드 파일은 해당 서비스의 관리 기능이 필요할 수 있습니다.
