1. 처리하는 정보와 목적

선택한 파일
사용자가 Android 시스템 선택기로 승인한 폴더와 하위 파일의 본문, 이름·경로·크기·수정 시각·내용 해시를 단방향 백업, 중복 재전송 방지와 수정본 보관에 사용합니다. 파일에는 녹음·영상·문서 및 민감한 내용이 포함될 수 있습니다.
연결 계정
계정의 이메일·표시 이름, Google 계정의 permission ID 또는 Microsoft drive ID와 OAuth 인증 정보를 계정 표시·접근 승인·클라우드 전송에 사용합니다. Google/Microsoft 비밀번호를 앱에 직접 입력받아 저장하는 방식은 사용하지 않습니다.
작업 설정·이력
선택한 폴더, 백업 목적지·감지 주기·네트워크/충전 조건, 전송 세션, 원격 파일 ID·내용 해시와 처리 결과를 백업 실행·재개·오류 확인에 사용합니다.

자체 회원가입은 제공하지 않고 기존 클라우드 계정을 연결합니다. 앱이 사용자의 모든 휴대폰 파일을 자동으로 읽는 것은 아니며 필요한 폴더를 직접 선택해야 합니다.

2. 전송되는 곳과 외부 서비스

사용자가 연결하고 백업 대상으로 선택한 Google Drive 또는 개인용 OneDrive에 파일과 메타데이터를 보냅니다. 계정 승인은 Google/Microsoft 서비스와 통신합니다. Google Drive에는 앱이 생성하거나 접근을 허용받은 파일을 다루는 범위를 요청하며 Drive 전체 파일 접근 권한을 요청하지 않습니다. OneDrive 연결 코드는 사용자 파일 읽기·쓰기와 오프라인 접근 권한을 요청합니다. 현재 OneDrive의 일반 사용자용 등록·검증은 준비 중입니다.

클라우드 백업은 기기 밖으로 파일을 전송하는 기능입니다. ‘모든 데이터가 휴대폰에만 남는다’고 설명하지 않습니다. 각 클라우드의 실제 저장 위치·계정 정보 처리·보관은 해당 계정 설정과 제공자의 정책에 따릅니다. 인증·클라우드 API 통신 과정에는 서비스에 전달하는 인증 정보 및 IP 등 요청의 연결 정보가 수반될 수 있습니다.

현재 앱에는 광고·별도 이용 분석 SDK를 직접 추가하지 않았습니다. Google 계정 승인은 Google Play 서비스 인증 SDK를 사용하며 해당 서비스의 정보 처리에도 제공자 정책이 적용됩니다. 제공자의 모든 처리가 없거나 전부 익명이라고 보장하지 않습니다.

3. 별도 PC 전사와 AI 선택 기능

PC 전사기를 별도로 설치하고 계정을 연결한 경우에만 PC가 Drive에 백업된 원본을 임시로 내려받아 로컬에서 음성을 인식합니다. PC가 켜져 있고 사용자가 로그인되어 있어야 합니다. 결과에는 전사 본문·구간 시각·원본 링크·녹음 시각의 근거·파일 해시와 처리 상태가 포함되며 Google Drive에 저장됩니다. 영상은 첫 음성 트랙을 처리하며 화면의 슬라이드·자막·채팅을 분석하지 않습니다. 인식 결과에는 오류가 있을 수 있습니다.

전사 모델의 첫 다운로드는 Hugging Face 등 모델 제공 인프라와 통신하며 해당 접속 정보가 제공자에게 전달될 수 있습니다. 다운로드된 모델의 음성 추론은 PC에서 실행합니다. 녹음싱크 전용 중앙 전사 API를 호출하는 코드는 현재 앱에 없습니다. 이 설명이 클라우드 백업이나 외부 AI 공유까지 오프라인이라는 뜻은 아닙니다. 일반 사용자용 PC 설치 앱은 아직 제공하지 않습니다.

AI 정리 요청 복사·시스템 공유는 사용자가 버튼을 눌렀을 때 수행합니다. 사용자가 외부 AI에 요청·링크·자료를 전달하면 그 서비스의 별도 계정·연결·처리 조건이 적용됩니다. 앱에서 요청을 복사했다는 이유만으로 외부 AI 계정 연결이나 반복 작업이 완료되는 것은 아닙니다. 이 기능 없이 백업만 사용할 수도 있습니다.

4. 보관과 삭제

  • Android 기기. 폴더/예약 설정과 전송 원장·로그는 앱 전용 저장소에 보관합니다. DB 처리 이력은 최근 500개를 유지하고 화면에는 최근 100개를 표시합니다. 파일 해시·원격 ID 등 중복 방지 원장은 로그와 별도로 보관합니다.
  • 계정 연결 해제. 기기에 저장한 해당 계정 인증 토큰을 제거합니다. 기존 처리 이력·클라우드 파일·Google/Microsoft 계정 자체까지 삭제하지 않습니다. 서비스의 앱 접근 승인은 각 계정 설정에서 별도로 철회할 수 있습니다.
  • 폴더 연결 해제. 백업 작업 설정을 제거하며 휴대폰 원본과 클라우드 백업은 보존합니다. 앱은 원본 삭제를 클라우드에 전파하지 않습니다.
  • 앱 데이터 삭제·제거. Android 설정에서 앱 데이터를 지우거나 앱을 제거하면 앱 전용 기기 정보가 제거됩니다. 클라우드에 이미 보관한 원본·수정본·전사본은 각 서비스에서 직접 관리합니다.
  • 별도 PC. 전사용 임시 다운로드는 성공·실패·중단 처리 후 정리합니다. 강제 종료로 남은 캐시는 다음 실행 때 원장으로 확인해 정리하도록 구현되어 있습니다. 모델·암호화 인증·로그·처리 이력은 별도로 보관합니다. 이 PC 데이터는 Android 앱 제거로 삭제되지 않습니다.

연결 해제와 파일/데이터 삭제는 다른 동작입니다. 모든 정보를 일정 일수 뒤 자동 삭제한다고 약속하지 않습니다. 사용자가 소유한 클라우드 파일의 보관 기간과 삭제는 사용자의 관리 및 해당 서비스 정책에 따릅니다.

5. 보안 조치

클라우드 요청은 HTTPS를 사용합니다. Android 인증 토큰과 전송 세션 정보는 Android Keystore의 키로 AES-GCM 암호화해 저장하고, PC 인증 토큰은 해당 Windows 사용자의 DPAPI로 보호합니다. 오류 이력에는 토큰·업로드 주소가 포함될 수 있는 원시 응답을 그대로 남기지 않도록 처리합니다. 기기와 모든 클라우드 사이의 종단간 암호화나 모든 위험의 제거를 보장하는 기능은 아닙니다.

6. Android 권한

인터넷·연결 상태
계정 승인·클라우드 전송과 사용자가 정한 네트워크 조건 확인에 사용합니다.
알림·dataSync 서비스
사용자가 시작한 백업의 실행·진행 표시·중지에 사용합니다.
재부팅 수신
사용자가 켜 둔 시스템 예약 작업을 복구하는 데 사용합니다.
선택한 폴더
Android 시스템 선택기에서 사용자가 승인한 폴더 접근을 사용합니다. 폴더가 승인되지 않았거나 권한이 회수되면 해당 파일을 읽을 수 없습니다.

마이크·SMS·통화기록·모든 파일 접근·광범위 사진/영상 권한은 선언하지 않습니다. 이미 만들어진 통화 녹음 파일의 백업을 위해 통화기록을 읽지 않습니다.

7. 권한 철회와 개인정보 문의

앱 안에서 계정/폴더 연결을 해제하고 Android 설정 및 각 클라우드 계정 설정에서 접근 승인을 관리할 수 있습니다. 로컬 앱 데이터와 사용자가 소유한 클라우드 파일의 삭제 범위는 위 설명을 확인해 주세요.

개인정보 열람·정정·삭제·처리 정지 등 관련 문의는 contact@patentwith.com으로 보내 주세요. 운영자 전승열이 처리 범위와 문의 내용을 확인합니다. 처음부터 비밀번호·인증 코드·녹음 원본을 보내지 마세요. Google/Microsoft 계정 자체나 사용자가 직접 소유·관리하는 클라우드 파일은 해당 서비스의 관리 기능이 필요할 수 있습니다.
